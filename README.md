Como parte del material del proyecto, además del [vídeo](https://studio.youtube.com/video/EbXoFNm7zcw/edit), se encuentran cuatro archivos MD:
- `decisions-diffs-harness.md`: decisiones que se han ido tomando a lo largo del desarrollo acompañadas de su justificación, sobre todo, si se alejan de la pauta que marca el curso.
- `future-improvements.md`: algunas de las decisiones que recoge el documento anterior están motivadas por el alcance del proyecto y la fecha de vencimiento del mismo.  Consciente de que, bajo esas premisas, no siempre se toman las resoluciones más acertadas, este otro documento detalla cómo mejorar aspectos deficientes.
- `module-1-summary.md` y `module-2-summary.md`: el enfoque con el proyecto ha sido imitar la estructura del curso, abordando cada módulo desde una sesión diferente. Estos dos documentos resumen el resultado de las dos primeras sesiones, es decir, el contenido de los módulos 1 y 2 del máster. A partir del 3º, la demostración está en el vídeo, con la ejecución de las diferentes skills para desarrollar las features implicadas.
